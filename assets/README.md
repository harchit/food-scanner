# Assets

Place your app icons and splash screen images here:

- `icon.png` - App icon (1024x1024 recommended)
- `splash.png` - Splash screen image (1284x2778 recommended)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024 recommended)

## Generating Assets

You can use tools like:
- [Expo App Icon Generator](https://expo.dev/tools)
- [Figma](https://figma.com)
- [Canva](https://canva.com)

## Color Scheme

The app uses a dark theme with green accents:
- Background: #0D1117
- Primary Green: #238636
- Halal Green: #2EA043
- Doubtful Yellow: #D29922
